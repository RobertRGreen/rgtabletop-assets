# RGTabletop assets

Public image host for the RGTabletop Rust server: in-game UI text graphics and server-browser / listing art.
Images only - server code and configs live in a private repo.

- `ui/v<n>/` - 2x transparent PNGs rendered from the private generator (Orbitron / Share Tech Mono). New version folder per change so clients never hold stale cached copies.
